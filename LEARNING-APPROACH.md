# How This Project Is Being Built

This project exists primarily as a hands-on way to build real backend engineering skill, not just to end up with a working app. That shapes how it's built:

- **Staged, not all at once.** The project is broken into phases, and each phase isn't "done" until that piece works end-to-end on its own. See `docs/superpowers/specs/` for each phase's design spec.
- **Full implementations, no imposed exercises.** Each phase is brainstormed into a design spec, approved, then built in full — no compartmentalizing into concept+exercise checkpoints. The pace of learning is controlled by the user, not baked into the build process.
